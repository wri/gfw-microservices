# Dependencies

- [Node.js](https://nodejs.org/en/) (>= 16)
- Axios
- dotenv

run `npm install dotenv axios` to install dependencies

# Configuration

Create an .env file and use the following template, replacing the values

```
API_BASEURL=https://pro-qa.globalforestwatch.org
API_TOKEN=your-api-token
```

# Run the script

Run `node index.js` to run the script
